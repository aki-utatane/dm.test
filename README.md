# dm.test

ダンジョンマスター（仮称）の第一層を、**実際に操作してログを回収するための公開テスト環境**です。

## v0.1 の対象

WT1相当の初回魔石発見から、第二層到達までを一続きでテストします。

- 初回42魔石
- コボルト3体 + ゴブリン2体を召喚
- 掘削 / 防衛 / 予備への配置
- 追加召喚
- WTごとの採掘・魔石・資源
- 40×40程度で下層への掘りポイントを発見
- 50×50以降の横掘り硬岩化
- 下方掘削
- WT7 / 10 / 15 / 18 の固定侵入
- 戦闘結果を経営側へ自動反映
- 配下死亡による損耗
- 補充召喚
- 第二層到達WT
- 全操作・戦闘ロール・経済状態のJSON / CSV出力

## 戦闘

手入力方式ではありません。固定WTに到達すると、その時点の防衛班で実際に戦闘へ入ります。

現在実装している採用済み骨格:

- 場は侵入者最大4 + 防衛側最大4
- 速度順
- 同速度は侵入者優先
- 同陣営は左優先
- 通常攻撃 = max(0, 2d6 + 攻撃 - 防御)
- DM側の手番ではプレイヤーが攻撃対象を選択
- 防衛側死亡は即座に経営側の配下数へ反映
- 4体を超える防衛班は待機し、空きが出ると投入

現段階で未確定または未実装:

- 固定侵入者ごとのアライメント
- 撤退 / 降伏
- 罠
- 特殊能力
- 魔法攻撃 / 回復が必要になる編成
- 作業中カードを戦闘へ投入する場合のペナルティ

固定侵入者のアライメントが未決定なので、侵入者の標的選択はテスト設定で
「ランダム / 最強 / 最弱」を切り替えられます。デフォルトはランダムです。

## 採掘 v0.1 仮置き

- フロア: 100×100
- 下層ポイント: 面積1600で発見（プレイヤーには事前表示しない）
- 横掘り: 2500以降は硬岩
- 下方必要量: 720
- 通常岩: 掘削力×4 / WT
- 硬岩・下方: 掘削力×1 / WT
- 魔石: 掘削力×0.225 / WT
- 資源: 掘削力×0.5 / WT

仮置き値は画面から変更でき、変更自体もログへ記録されます。

## 再現性

戦闘の2d6はseed付き疑似乱数です。

同じseed、同じ操作、同じ設定なら、原則として同じ出目を再現できます。

## データ回収

画面下部から以下を出力できます。

- JSON: セッション全状態・全イベント・戦闘ロール
- CSV: イベント単位の分析用データ
- 集計コピー: チャットへ貼り付ける簡易サマリー

データは端末のlocalStorageにも自動保存されます。
